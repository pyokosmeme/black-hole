# KV usage investigation — September 12, 2026

Cloudflare's GraphQL analytics for the SESSIONS namespace confirmed **101,547
reads, 281 writes, 1,194 lists, and 2 deletes** for September 12 UTC. The screenshot
shows the same totals rounded. A read-only KV key-list request was rejected with
Cloudflare error 10048: the day's free usage allowance was exhausted.

Reads were sustained throughout the day, mostly about 3,700–6,400 per hour. This
is not evidence of a sudden write burst caused by the editor. Aggregate KV
analytics do not identify individual caller URLs, so an exact attribution of
every operation is unavailable from these totals.

## Sources of amplification in the labeler

- Each open `subscribeLabels` socket read `labeler:seq` every five seconds:
  17,280 reads per connection per full day, even without new labels.
- Stream reconnections and new-label polls listed and read the entire label
  collection before filtering by the consumer's cursor.
- Every `queryLabels` request likewise listed and read all labels before
  filtering by subject. Requests for an unrelated source did this too.
- Diagnostic connection probes performed another KV read per request and
  stored hourly probe records.
- Close handlers were installed only after asynchronous replay, allowing an
  early disconnect to miss cleanup. Async interval callbacks could overlap.

The five-minute scheduled job also reads an opt-in marker for each labeler liker
on every run. It writes only for newly discovered likers. Opening the subscription
popup performs no KV request; form submission uses the subscription endpoint.

## Changes and verification

- At the user's request, stream polling now waits ten minutes between completed
  polls: 144 idle head reads per connection per full day, plus connection setup
  and any new-label reads. This is 120 times less frequent than the original
  five-second polling. Sockets remain open for up to an hour to reduce reconnect
  overhead. Replay and updates fetch only keys after the cursor, with no KV lists.
- Socket close/error/lifetime cleanup is registered before replay. Slow reads
  cannot overlap polls; quota failures wait for the next normal interval.
- Public query records use a five-minute Workers Cache API cache. Only public
  label fields are cached. Admin writes/deletes and scheduled additions
  invalidate the local cache; other locations expire within five minutes.
- Diagnostic KV probes were removed. Invalid requests and queries for other
  labeler sources use no KV operations.
- Subscription modal spacing uses one header padding, with no extra stripe
  margin at desktop or mobile widths.

All 44 Node tests passed, including eight new tests for operation counts, cache
expiry/invalidation, incremental replay, early disconnects, and slow/failed KV
reads. Browser checks at 1280px and 390px confirmed zero stripe bottom margin,
24px/12px header padding respectively, and no horizontal overflow.

These changes reduce future usage; they do not reset an exhausted daily quota.
Cache efficiency depends on traffic across Cloudflare locations. Monitor read
and list totals after deployment and the next daily quota reset.
